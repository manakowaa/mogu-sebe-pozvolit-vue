# «Могу себе позволить?» — Vue 3

Интерактивный калькулятор помогает оценить крупную покупку с учётом дохода, расходов, накоплений, кредитных платежей и желаемого финансового резерва.

## Возможности

- Тёмная цветовая гамма исходного калькулятора и адаптивная компоновка.
- Блок «Ближайшая цель» с вариантами: финансовый запас, переезд, жильё, путешествие, инвестиции или отсутствие конкретной цели. Выбор отражается в рекомендациях.
- Отдельный блок «Персональная работа»: описание пользы разбора, этапов взаимодействия и подготовленное обращение в Telegram автора: https://t.me/manakovavs.

- Реактивный расчёт результата и рекомендаций при изменении значений.
- Отдельные Vue-компоненты для формы, результата и рекомендаций.
- Расчёт целевого резерва на 3, 6 или 12 месяцев либо ввод суммы вручную.
- Валидация обязательных полей: доход и цена покупки должны быть больше нуля.
- Автоматическое сохранение данных в `localStorage` этого браузера.
- Восстановление профиля после перезагрузки страницы.
- Адаптивная раскладка для мобильных экранов.
- Кнопка сброса сохранённых данных.

## Архитектура

- `App.vue` хранит состояние формы, загружает и сохраняет профиль, вычисляет резерв и результат через `computed`.
- `ProfileForm.vue` отображает поля и отправляет изменения через `v-model`.
- `ResultPanel.vue` показывает статус покупки и ключевые показатели.
- `RecommendationPanel.vue` выводит выбранную ближайшую цель, рекомендации и отдельный блок персональной работы.

Расчёт является ориентировочным инструментом для самостоятельной оценки и не заменяет индивидуальную финансовую консультацию. Данные профиля сохраняются в локальном хранилище браузера и не отправляются на сервер.

## Идея проекта для портфолио

Проблема: перед крупной покупкой человеку сложно одновременно учитывать остаток накоплений, регулярные расходы, кредитные платежи и финансовый резерв.

Решение: веб-калькулятор, который сводит основные показатели в один интерфейс и сразу показывает ориентир по покупке и практические следующие шаги.

Что демонстрирует проект: декомпозицию интерфейса на Vue-компоненты, реактивное состояние, вычисляемые значения, валидацию, сохранение пользовательских данных и адаптивную верстку.

## Автоматические тесты финансовых расчётов

Тесты написаны на встроенном модуле `node:test`, поэтому отдельный тестовый фреймворк устанавливать не нужно.

npm test

Покрыты разбор денежных значений, автоматический и ручной резерв, свободный остаток, сумма после покупки, уровни рекомендаций и расчёт срока накопления.
